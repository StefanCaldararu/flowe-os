# Formatting test

Plain paragraph text wraps at word boundaries across the width of the screen, just like a book page would.
A single newline is a line break, like Obsidian.

Text with **bold**, *italic markers removed*, ~~strikethrough removed~~, ==highlight removed== and `inline code`.

## Lists
- A bullet
- Another bullet
	- Nested one level
		- Nested two levels
1. First numbered
2. Second numbered
10. Wide numbers line up

## Tasks
- [ ] Something still to do
- [x] Something finished
- [ ] A task with a longer description that has to wrap onto a second line of the screen

## Quotes and callouts
> A plain quote gets a bar on the left.
> > And quotes can nest.

> [!tip] Callouts show their title in bold
> And their body as a quote.
